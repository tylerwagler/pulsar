# docs/history

These documents are retired and kept for the record. They are dated reviews,
bring-up runbooks, finished plans and measurement maps. Each one opens with a
line saying what it was, when it was written, and where it used to live. Their
bodies are as they were, except that internal host names, addresses and private
paths were replaced with placeholders (`[IP]`, `pair-a`/`pair-b`,
`<private-notes>`, `/path/to/models/`) before publication. They are not
maintained, and the code at the tip of `dev` is the authority.
